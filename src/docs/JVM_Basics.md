
What is JDK?

JDK= JRE + JVM + Development tools
JDK is Java Development Kit 
It includes the tools required for java development - editor, compiler, debugger and java runtime environment

What is JRE?

JRE is Java Runtime Environment.
JRE = JVM + java internal libraries ( java.lang,java.io..etc)
It is the environment in which java program executes.

What is JVM ?

JVM is the Java Virtual Machine
It is the execution engine which actually converts the bytecode into machine code.
We need to install platform(OS) specific JVM . 

What is bytecode?

Bytecode is an intermediate code . It is not the high level language.
Its is the result we get after compiling .java files.


“write once, run anywhere” means 

Java source code written on one machine ( OS - Windows ) need not be compiled again on other machine ( OS - Mac)
One just need to download the OS specific JVM.
Java is platform independent language because of the concept of bytecode.
JVM is platform dependent but it makes java platform independent.
Java code(.java files) written on one platform(Windows) can be run directly without the need of recompilation on other platform(Mac)  
along with JVM which makes it portable. 
JVM converts the source code into native code unlike C
